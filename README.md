Cursor AI Alternative

A browser-based cloud IDE inspired by Cursor, built with Next.js, React, TypeScript, and modern AI tools.

> Part 1 of 2 — Chapters 1–12. Part 2 will add the AI Agent, WebContainer, terminal/preview, and GitHub integration.

## Features

- Real-time code editing
- AI code suggestions & Quick Edit (`Cmd+K`)
- AI conversation assistant
- Multi-file project management
- File explorer & editor
- Real-time database updates
- Authentication

## Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS
- **Editor:** CodeMirror 6
- **Backend:** Convex, Inngest
- **AI:** Claude Sonnet 4 / Gemini 2.0 Flash
- **Auth:** Clerk
- **UI:** shadcn/ui, Radix UI
- **Planned:** WebContainer, xterm.js, GitHub API
